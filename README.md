  This project is a high-performance superscalar out-of-order processor core implemented in Chisel, currently based on the 32-bit LoongArch instruction set architecture. It is designed to explore advanced microarchitectural techniques and features a robust pipeline capable of fetching, issuing, and committing up to two instructions per clock cycle. The core is fully synthesized and integrated with an AXI4 memory interface, making it a comprehensive component for complex computing workloads and operating system deployment.


  The instruction fetch frontend utilizes a decoupled architecture with a fetch buffer to smooth out instruction delivery to the decode stage. To minimize pipeline flushes, it features a highly accurate zero-bubble branch prediction unit. This unit incorporates a 512-entry Branch Target Buffer, a Return Address Stack, and a sophisticated Tournament Predictor that dynamically arbitrates between a 1024-entry Bimodal predictor and a 1024-entry GShare predictor based on historical accuracy.


  At the heart of the processor is a dynamic execution engine that performs register renaming to eliminate false data dependencies, utilizing a physical register file and an active register alias table. The out-of-order issue queue monitors data readiness through a comprehensive bypass network and early wakeup signals, dispatching instructions to four independent execution ports. These ports include two arithmetic logic units, a multiply-divide unit, and an address generation unit, all coordinated by a 32-entry Reorder Buffer to ensure precise exception handling and in-order commit.


  The memory subsystem is highly optimized, featuring a fully associative Translation Lookaside Buffer supporting Direct Mapped Windows and paging. The Load-Store Queue supports out-of-order memory access with aggressive Store-to-Load Forwarding and memory violation detection using content addressable memory. The L1 instruction and data caches are non-blocking, integrating Miss Status Handling Registers to handle multiple outstanding misses simultaneously. The caches employ a one-read-one-write physical array, hardware prefetchers, and a tree-based pseudo-LRU replacement policy, all connected to the system bus via a high-performance AXI4 bridge with deep skid buffers for timing isolation.


  While the current LoongArch-based microarchitecture is highly detailed and successfully passes the CoreMark benchmark in software simulation, it is currently considered an experimental prototype. The design exhibits unresolved bugs and unexplained stability issues when synthesized and deployed on physical FPGA hardware. Moving forward, the primary roadmap for this project involves a complete refactoring of the architecture to support the RISC-V instruction set. Transitioning to RISC-V will help isolate and resolve the current hardware deployment anomalies while leveraging a broader open-source ecosystem, all while building upon the advanced superscalar out-of-order foundation established in this iteration.
